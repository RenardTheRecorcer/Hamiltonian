Hamiltonian Cycle — Overview
Core idea. Find a cycle that visits every vertex in the graph exactly once and returns to the starting vertex.
NP-Complete: No known polynomial-time algorithm exists. We compare brute-force O(n!) with the Held-Karp DP approach O(2n · n2).

Brute-Force: Try all (n−1)! permutations of vertices. For each, check if consecutive vertices are connected and if the last connects back to the start.

Held-Karp DP: Use bitmask DP where dp[S][v] = true if there is a Hamiltonian path visiting exactly the vertices in subset S, ending at v. Build up from subsets of size 2 to n.

Applications: Circuit board testing (visiting all test points), DNA fragment assembly, route planning, and the Travelling Salesman Problem (weighted variant).

Worked Example
Consider a pentagon graph with vertices 0–4 and edges forming a cycle: 0-1, 1-2, 2-3, 3-4, 4-0. Starting at vertex 0, Held-Karp fills dp[{0,1},1]=true, dp[{0,4},4]=true, etc. Eventually dp[{0,1,2,3,4},v]=true for some v adjacent to 0 confirms a Hamiltonian cycle exists. The cycle is 0→1→2→3→4→0.
NP-Completeness Proof Sketch
Step 1 — In NP: Given a sequence of vertices, verify it's a valid HC in O(n): check all vertices appear exactly once, consecutive pairs are edges, and last connects to first.
Step 2 — Reduction from Vertex Cover: Given a Vertex Cover instance (G, k), construct widget subgraphs for each edge of G. A Hamiltonian cycle in the constructed graph ↔ a vertex cover of size k in G. The construction runs in polynomial time.

Forward: If G has a vertex cover of size k, the cover vertices "traverse" their edge widgets in a way that forms a Hamiltonian cycle.

Backward: If the constructed graph has a HC, the cycle structure forces exactly k "selector" vertices to cover all edges.

Key Concepts
  • Bitmask DP: Represent visited vertex subsets as integers. Bit i is set if vertex i is visited.
  • Optimal substructure: A Hamiltonian path through S ending at v extends a path through S\{v} ending at some neighbor u of v.
  • Difference from Euler: Eulerian circuit visits every edge once (poly-time checkable). Hamiltonian cycle visits every vertex once (NP-complete).
  • Common mistake: Assuming greedy (always go to the nearest unvisited vertex) finds a HC. It does not.

Why Hamiltonian Cycle is NP-Complete

              

                In NP: A certificate (vertex sequence) can be verified in O(n) time by checking adjacency and uniqueness.


                NP-Hard: Vertex Cover ≤p Hamiltonian Cycle. The polynomial-time reduction constructs edge widgets that force a HC to correspond to a valid vertex cover.


                Design Paradigm — DP: Held-Karp exploits optimal substructure: a path visiting set S ending at v can be built from paths visiting S\{v} ending at a neighbor of v. The bitmask encodes which vertices are visited, giving 2n·n states instead of n! permutations.
